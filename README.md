# Assignment 4 — Function tasks

Набор из 15 небольших программ, в которых каждая задача оформлена в виде отдельной функции. Цель — потренироваться в написании функций, циклов (в том числе вложенных) и работе с цифрами числа.

## Описание задач

### 1. Полоса из символов
Вывести строку из `n` одинаковых символов.
```
Input:  7
Output: #######
```

### 2. Пустой квадрат
Вложенными циклами вывести квадрат `N×N`: рамка из `*`, внутри пробелы.
```
Input: N = 4
Output:
****
*  *
*  *
****
```
> В условии внутренняя строка показана как `*   *` (5 символов), но для квадрата 4×4 правильно `*` + 2 пробела + `*`.

### 3. Перевёрнутая пирамида
Высота `N`. В первой строке `2N-1` звёзд, в каждой следующей на 2 меньше. По желанию — выровнять по центру отступами.
```
Input: N = 3
Output:
*****
 ***
  *
```

### 4. Матрица N×M
Заполнить последовательными числами от 1 до `N*M`, вывести по `M` чисел в строке.
```
Input:  2 3
Output:
1 2 3
4 5 6
```

### 5. Простое число
`isPrime(n)` возвращает `true`, если `n` простое, иначе `false`. Достаточно проверять делители до `√n`. Числа меньше 2 не являются простыми.
```
Input:  29
Output: Prime
```

### 6. Простые числа в диапазоне
Перебрать все числа от `A` до `B`, посчитать те, для которых `isPrime` вернула `true`.
```
Input:  A = 10, B = 30
Output: Prime Count = 6      (11, 13, 17, 19, 23, 29)
```

### 7. Факториал
`factorial(n) = 1 × 2 × … × n`. Для больших `n` используйте тип с большим диапазоном (`long long` / `BigInteger` и т. п.).
```
Input:  5
Output: Factorial = 120
```

### 8. Десятичное в двоичное
Делить число на 2, запоминать остатки и собрать их в обратном порядке. Результат — строка.
```
Input:  13
Output: Binary = 1101
```

### 9. Числа Армстронга
Число Армстронга равно сумме своих цифр, возведённых в степень количества цифр (для трёхзначных — в куб). Например, 153 = 1³ + 5³ + 3³.
```
Input:  None
Output: 153 370 371 407
```

### 10. НОД
Алгоритм Евклида: `gcd(a, b) = gcd(b, a % b)`, пока `b ≠ 0`.
```
Input:  24 36
Output: GCD = 12
```

### 11. НОК
Через НОД: `lcm(a, b) = a / gcd(a, b) * b`.
```
Input:  6 8
Output: LCM = 24
```

### 12. Разворот числа
В цикле брать последнюю цифру (`n % 10`) и добавлять в результат (`rev = rev * 10 + digit`).
```
Input:  1234
Output: 4321
```

### 13. Узор «X»
Звёздочка ставится в позиции, где `i == j` или `i + j == n - 1`, в остальных — пробел.
```
Input: 5
Output:
*   *
 * * 
  *  
 * * 
*   *
```

### 14. Преобразование цифр
Чётная цифра увеличивается на 1, нечётная уменьшается на 1. Результат собирается обратно в число (с учётом порядка цифр).
```
Input:  983210
Output: 892301
```
Разбор: 9→8, 8→9, 3→2, 2→3, 1→0, 0→1.

### 15. Палиндром
Число равно своему развороту (можно использовать `reverseNumber` из задачи 12).
```
Input:  121
Output: Palindrome
```
Если число не палиндром, выводится `Not palindrome`.

## Общие требования

- Каждая задача оформлена отдельной функцией с указанным именем и сигнатурой.
- Ввод данных и вывод результата выполняются в `main` (функции не должны зависеть от ввода).
- Формат вывода должен совпадать с примерами из условия.
- Вспомогательные функции (`isPrime`, `isArmstrong`, `isPalindrome`) возвращают логическое значение.
